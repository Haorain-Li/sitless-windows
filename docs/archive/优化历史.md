# 起身 · Sit Less 优化记录

正式版本：1.0.0，日期：2026-10-26。

## v1.1.1 浮窗与菜单（本地构建）

- 右上角新增精简 / 展开快捷按钮，两种布局都能直接操作，并提供悬停说明与可访问名称；提醒待处理时保留自动展开规则。
- 三个点与收起按钮改用统一绘制的线条图标，避免依赖字体字符的外观差异。
- 扩展菜单改用浅色圆角面板、图标、分组细线与圆角悬停效果；开关显示绿色勾选，退出项用单独颜色，右侧快捷键统一对齐。
- 浮窗与托盘共用该菜单，保留原生菜单操作和状态同步。菜单字体与行高随缩放调整，关闭时释放字体。
- 386 项现有断言通过；100% / 150% / 200% 下完成精简按钮、菜单操作 / 勾选 / 选择状态和行对齐的进程内检查，检查浮窗 / 精简 / 菜单预览。

## v1.1.0 每日打卡（本地构建）

- 新增提肛与喝水每日打卡：浮窗直接确认 / 撤销，次日按本地日期重置，历史每项每日最多计 1 次。
- 独立“今日 / 历史 / 提醒与目标”窗口；显示累计次数、全部完成天数和当日目标。保存按钮固定，空间不足时内容可滚动。
- 默认每天 20:00 对未完成项目合并提醒一次，可调时间并分别关闭；服从全屏免打扰，锁屏与活动提醒期间延后，次日不追补。
- 饮水提供 1.5 L / 1.7 L 及个人目标，注明成年人饮水参考的适用条件；提肛按个人计划确认，不规定统一训练量。
- 历史单独存为本机 XML，原子替换并维护备份；损坏时恢复并保留原件，失败可见且重试。新文件不纳入 Git 或便携包。
- 增加 118 项打卡断言，总计 386 项通过；保留此前按钮绘制与免打扰修复。此次尚未发布到 GitHub。

## 开发阶段 1.2.0：全屏自动免打扰

- 默认启用，可在设置和托盘菜单切换；兼容旧设置文件，开关选择持久保存。
- 结合 Windows 独占 Direct3D 全屏状态和前台窗口客户区覆盖显示器的判断，兼顾无边框全屏；不以进程名称猜测游戏，不读取窗口标题。
- 全屏期间自动隐藏浮窗、取消置顶、屏蔽声音与气泡；计时继续，保留手动暂停。
- 退出全屏稳定约 3 秒后恢复置顶偏好；原先隐藏的浮窗不无故展开，待处理提醒只补发一次，已处理提醒丢弃。
- 增加 53 项全屏免打扰断言与一次只读原生接口检查；原有 71 项计时与 144 项绘制断言仍通过。
- 调整设置页布局，新增开关在默认大小下可直接看到；全屏视频 / 演示也会静默，规则在界面和使用说明中注明。
- 新增 `优化方案清单.md`，列出后续优先级、相对成本及验收标准；尚未实现的建议明确标注。

## 开发阶段 1.1.2：黑角修复

- 根据实际窗口截图确认：问题是圆角外侧的黑色块，不能由焦点框解释。
- 确认按钮继承的 `Opaque` 样式为 true，实际 `WM_PAINT` 会跳过 `OnPaintBackground`。1.1.1 在该回调中填充背景的尝试未覆盖真实重绘路径。
- 将完整底色填充移入 `OnPaint`，每次绘制时先覆盖整块缓冲区，再绘制圆角和文字。
- 新增黑色缓冲区回归检查：旧实现在普通按钮的第一个角点即失败；修复后两种背景、三种缩放和六种状态的 144 个角点检查全部通过。
- 设置窗口标题显示实际版本号，便于区分仍在运行的旧程序。

## 开发阶段 1.1.1：按钮修复尝试

- 将 Windows 默认的矩形虚线焦点框替换为主题色圆角描边，保留键盘焦点反馈。
- 尝试在背景回调中填充圆角外侧，并关闭系统主题背景混绘；后续用户截图确认黑角仍存在，实际修复见 1.1.2。
- 增加空格键按下反馈，调整尺寸或切换焦点时及时重绘。
- 构建支持 `-OutputDirectory` 指定输出目录，程序占用旧文件时可另行生成修复版。

基于 Haorain-Li/sitless-windows 的 c0899ec 版本，在保留原生 Windows 窗体和无第三方依赖的基础上优化。

- 重新安排浮窗留白与字体层次，突出倒计时。
- 独立展示今日活动次数与桌前计时，保留提醒和活动完成时的自动展开。

## 可靠性

- 修复保存相同提醒间隔时取消既有延后的问题；只改活动时长或其他偏好会保留延后。修改提醒间隔时重新计算阈值。
- 重建菜单时释放旧菜单项，关闭设置窗口时释放其自建字体。
- 成功保存设置后恢复正常的菜单提示，避免继续显示旧的保存错误。

## 验证与使用

- 71 项计时断言通过，新增回归用例先复现旧版问题再验证修复。
- 1.1.0 阶段检查 100%、150%、200% 布局缩放下的八种状态预览；1.1.1 另检查 150% 缩放的键盘焦点、正常浮窗和设置页预览。
- 1.1.0 阶段演示进程运行 12 秒，跨过 10 秒提醒时点，窗口保持响应。
- 桌面交互工具因本机组件缺失无法运行；真实点击、快捷键、锁屏 / 休眠和跨显示器行为仍需手动验收。详细范围见 `验证说明.md`。

解压便携包到可写文件夹，双击 `SitLess.exe`。演示可使用 `SitLess.exe --demo`，不会保存演示数据；完整操作见 `使用说明.md`。

源码构建：运行 `build.ps1`，生成 `dist/SitLess.exe`；运行 `package.ps1` 生成发布文件。仓库的 `portable/` 目录随正式发布更新。
