## 界面与分发

- 检查 100% / 150% / 200% 预览缩放下的浮窗、设置、自启动开关与打卡日历；预览使用示例数据。
- 去掉浮窗原生尺寸 / 标题边框和类阴影，激活消息不能引入额外尺寸；客户区移动 / 拖动与捕获清理通过回归。该检查不等同于真实桌面无灰框的截图验收。
- 窗口缩放检查覆盖窄 / 宽 / 高布局、两种模式独立还原、屏幕工作区与已有计时 / 打卡保留。
- 便携包按白名单创建，核对条目、程序哈希、本地文档与图片链接，不包含用户 XML、备份和测试程序。
- 短时重复拖动验证字体数量和 GDI 资源上限；没有宣称完成长时间 CPU / 内存采样。过去的读数保存在 [验证历史](archive/验证历史.md)。

## 实机验收清单

1. 从托盘退出旧版，启动 v1.1.0，核对设置版本。反复点击浮窗背景、文字和按钮，切换焦点，确认没有额外灰框。
2. 从四边与四角拖动，切换精简 / 展开、还原大小，再关闭重启；检查位置、尺寸及鼠标光标。拖动时切换窗口或按快捷键，确认不粘住鼠标。
3. 在设置里关闭自启动并保存，检查登录启动项；再开启并登录验证收起到托盘。移动程序后手动运行一次，检查启动路径更新。系统策略可能覆盖应用设置。
4. 勾选打卡后退出，移动程序再启动，确认同一 Windows 用户的记录保持；旧记录在其他目录时测试日历页导入。核对月份、闰日与当日目标。
5. 在真实游戏、锁屏 / 休眠、通知策略及不同 DPI 显示器下验收。

桌面验证组件在本机返回 os error 3，当前未自动操作真实鼠标、注销登录或游戏。因此上述清单是待验收步骤，不表示已经完成，也不能承诺所有环境零缺陷。
