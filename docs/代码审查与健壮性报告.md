# 代码审查与健壮性报告

版本：v1.1.0 发布构建。日期：2026-10-26。

## 审查范围与结论

本轮进行本地静态代码审查、故障注入和进程内回归，重点检查窗口激活 / 拖动、自启动、数据迁移与保存、历史导入、月历日期边界。已处理下列发现，全部 2,560 项断言通过，当前检查范围未发现尚未处理的阻断问题。

这不是对所有 Windows 环境零缺陷的保证。桌面 Computer Use 组件返回 `failed to launch codex app-server: 系统找不到指定的路径。 (os error 3)`，因此不能将静态截图和进程内事件等同于真实鼠标点击或登录启动验收。

## 发现与处理

发布前检查还发现尺寸测试假设屏幕高度足够，且直接设置 ClientSize 的结果不一定已经过布局限幅，在 GitHub 的 720p 桌面上将正确的屏幕限制误报为失败。已按保存的逻辑尺寸与实际工作区检查布局后的预期，并增加两项 720p 工作区边界断言。独立 Windows 持续检查通过后再创建发布标签；开发构建与测试重试不增加正式版本号。

| 优先级 | 发现 | 修复与回归 |
| --- | --- | --- |
| P1 | 打卡文件绑定程序文件夹，移动或升级到新目录时看起来丢失 | 改为当前用户固定目录 `%LOCALAPPDATA%\SitLess`；首次迁移同目录旧数据，保留原件；测试移动程序后读取不变、已有记录不被旧数据覆盖 |
| P1 | 空设置对象与格式合法但内容无效的 XML，可能绕过异常兜底 | 明确拒绝 null、无效日期 / 重复日期，并将 `InvalidDataException` 纳入预期存储异常；验证回退、备份恢复及原件保留 |
| P2 | 上一版隐藏的原生尺寸边框及类阴影仍可能在激活时绘制，形成灰框 | 去掉原生标题 / 尺寸边框与类阴影，屏蔽非客户区绘制；用客户区捕获处理移动和八方向缩放；检查样式、激活消息及尺寸一致性。真实灰框效果仍待实机确认 |
| P2 | 自启动项修改与偏好保存可能不一致，失败后仍可能关闭设置窗口 | 保存偏好后再更新并读回启动项；失败恢复原偏好与启动值，显示错误并允许重试；使用模拟权限错误与忽略写入验证，不改真实注册表 |
| P2 | 迁移失败后继续写默认数据，会阻止后续自动迁移 | 迁移错误期间阻止偏好与打卡写入，暂不注册自启动；显示提示，修复权限后重启重试 |
| P2 | 多次导入可能超出历史容量，写入时才失败 | 导入前先验证所有记录与合并后的 50,000 天上限；无效或超限数据在修改前拒绝，重复导入不重复计数 |
| P2 | 拖动期间捕获丢失、快捷键或销毁窗口，可能遗留拖动状态或资源 | 结束 / 丢失捕获 / 按键 / 销毁时清理状态；验证中断、重复释放、销毁与字体数量、GDI 资源上限 |

## 故障注入与边界检查

- 数据：旧目录迁移、保留原件、固定目录优先、源文件被锁、错误目录、重试、原子保存、备份恢复、空 XML、DTD、无效数值、语义无效历史、超量导入。
- 自启动：默认开启、关闭后恢复、中文 / 空格路径加引号、搬移后更新路径、幂等操作、读取 / 写入权限拒绝、写入后读回、偏好保存失败与回滚。
- 日历：周一开头、完整月份、闰年与世纪例外，覆盖 1 / 1900 / 2000 / 2024 / 2026 / 2100 / 9999 年；最早与最晚日期、键盘跨月及月份导航边界。
- 拖动：八个方向的尺寸约束与对边锚点、负坐标、实际客户区宽高变化；100% / 150% / 200% 各反复 200 次，检查捕获释放、字体数量和有界 GDI 资源。短时资源检查不替代长期趋势测试。
- 隔离：测试使用临时目录和模拟启动项；检查真实用户偏好与打卡文件的写入时间未变化。演示与预览不迁移或保存真实数据，不写真实登录启动项。
