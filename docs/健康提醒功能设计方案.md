# 每日提肛与喝水打卡：设计与依据

功能引入于 v1.1.0，2026-10-26。当前项目版本见 [README](../README.md)。实现每日打卡、每天一次提醒、次日刷新和历史次数；不加入训练节拍或每隔几十分钟喝水的提醒。

## 用户流程

- 普通浮窗直接显示提肛 / 喝水两个按钮。用户确认完成后打勾，再点可撤销；每项同一日期最多计 1 次。
- “历史 / 设置”和托盘菜单进入三个页面：今日打卡、历史记录、提醒与目标。
- 今日页显示日期、状态和累计天数。历史页按日期倒序显示两项确认、当日饮水目标，统计累计次数与全部完成天数；次数就是已确认的日期数。
- 按电脑本地日历日期刷新；退出后第二天再启动，同样显示新一天。历史不清零，不把未运行过的日期自动算作失败或补打卡。
- 调整电脑时间回到已有日期时，复用该日期原记录，避免重复计数。不提供修改过去日期的入口。

## 提醒规则

默认每天 20:00，将启用且未完成的项目合并提醒一次；这是产品默认时间，不是医学推荐时间。可修改时间、分别关闭两项提醒。当天过了时间才启动，会提醒当日尚未完成的项目。

全屏免打扰、锁屏、休眠、打开设置或打卡页、正在活动计时以及待处理的活动提醒会延后每日提醒；不把尚未显示的提醒标为已提醒。当天恢复允许提醒后发送；跨天则丢弃旧日提醒。手动暂停久坐计时不会关闭每日提醒。

已完成的项目不提醒；当天已发过的合并提醒不因重启、撤销或调整时间而再发。通知只显示“还有几项打卡待确认”，不在气泡中暴露提肛等个人项目。声音沿用现有提示音偏好。软件退出期间不运行，也不会提醒；Windows 通知策略可能影响气泡显示。

## 饮水目标如何确定

软件默认提供可编辑的 1.5 L 个人目标，另有 1.7 L 预设和自定义。适用参考来自《中国居民膳食指南（2022）》等：温和气候、低活动成年女性直接饮水量约 1500 mL、男性约 1700 mL。国家疾控局刊载的中国疾控中心文章将直接饮水与包含食物水的总水量明确分开。

因此，1.5 / 1.7 L 是有适用条件的参考，不是所有人的统一合格线；天气、运动、年龄、生理和疾病情况会影响个人需要。有医嘱限液时按医嘱设置。软件不根据身体情况计算医疗目标，不要求集中补水，不把食物水的总摄入量当作额外饮水任务。

用户达到自己的全天目标后手动确认，不需要逐杯记录，也不会由程序检测实际饮水。改目标须点击保存，应用于今天与未来新建的日期，并取消今天旧目标下的喝水确认；历史日期保留当日目标和确认状态。

自定义输入的上下限仅用于限制软件输入和数据格式，不表示该范围内所有数值适合饮用。

来源：[国家疾控局刊载《中国疾控中心：国家喊你多喝白开水、淡茶水！》](https://www.ndcpa.gov.cn/jbkzzx/c100040/common/content/content_2104761364364300288.html)，2026-09-17，核对于 2026-10-26。

## 提肛打卡如何避免误导

这里的“提肛”按盆底肌训练相关的个人计划理解。NIDDK 的说明指出，盆底肌训练可帮助适合的男性和女性，但并非所有人都适合；动作包括收缩、保持与充分放松，训练计划应结合个人情况，不应过量。

因此，本功能仅确认“完成今日个人计划”，不把一次点击当作训练一次，也不规定所有人统一的每日次数、收缩秒数或疗效周期。开始前可咨询专业人员；疼痛或难以放松时暂停并咨询。软件不检测动作正确性或治疗效果。

来源：[NIDDK：Kegel Exercises](https://www.niddk.nih.gov/health-information/urologic-diseases/kegel-exercises)，页面标注最近审核 2021-11，核对于 2026-10-26。

## 数据与异常处理

每个本地日期只有一条记录，包含日期、提肛确认、喝水确认、当日饮水目标、是否已发送每日提醒。设置保存在 `sitless.settings.xml`，历史单独保存在 `sitless.checkins.xml`；从 v1.3.0 起均位于 `%LOCALAPPDATA%\SitLess`，不联网、不上传。

修改打卡立即尝试保存，使用临时文件与原子替换，维护 `.bak` 备份。保存失败显示提示并保留内存中的记录，稍后重试；主记录损坏时尝试备份，下次保存前保留损坏原件。恢复的备份可能比最近一次操作旧。移动或升级软件不会改变固定目录；旧版同目录记录会迁移，也可从日历页导入旧文件，详见 [使用指南](使用说明.md)。

打卡数据、备份和临时文件已加入 Git 忽略规则；打包只使用程序及说明文档白名单。演示和渲染不读取或写入个人打卡历史，预览数据为示例。
