# 起身 · 久坐提醒

一个轻量的 Windows 桌面浮窗，提醒你定期中断桌前工作、起身活动。双击 **SitLess.exe** 即可使用，无需安装；建议使用 Windows 10/11 与系统自带的 .NET Framework 4.8。

当前版本：1.3.1。更新时请先从托盘退出旧版，再打开新包；设置窗口标题中的版本号应显示 v1.3.1。v1.3.1 已整合此前本地迭代的每日打卡、快捷菜单与拖动缩放功能。

## 随 Windows 登录启动

- 默认开启，首次正常运行会注册当前 Windows 用户的登录启动项，不需要管理员权限。自动启动时收起到托盘，计时与打卡提醒按原规则运行。
- 在“设置 → 偏好设置”取消或勾选“随 Windows 登录启动”并保存；关闭后会移除本软件的启动项。
- 保存偏好或更新启动项失败时显示提示并保留设置窗口，允许重试。Windows 系统的启动项策略仍然有效。
- 移动程序后，手动运行新路径中的程序一次以更新启动路径。演示、渲染和测试不会注册真实启动项。

## 移动与调整大小

- 拖动浮窗背景或文字移动窗口；拖动任一边缘或四角调整大小，边缘会使用 Windows 的缩放光标。右下角两条短线提示可拖动区域。
- 调整时按钮、统计卡片与文字随尺寸适配。普通浮窗最小约 320 × 360、精简浮窗最小约 260 × 84，单位为 100% 系统缩放下的像素；高缩放下相应增大。最大尺寸会受所在屏幕工作区限制。
- 普通与精简浮窗分别记住宽高，切换模式或重启后恢复。系统缩放不变时会恢复相同大小；设置文件保存逻辑尺寸，避免在不同启动缩放下直接复用旧的物理像素。
- 在三个点菜单点击“恢复默认大小”，或在浮窗获得焦点时按 `Ctrl+0`，仅还原当前模式的大小；默认普通浮窗 344 × 390，精简浮窗 280 × 88。
- 调整尺寸不重置计时、暂停状态或打卡记录。提醒到时 / 活动完成时仍会临时展开，随后回到原来的精简尺寸。
- 浮窗内容区域保持可拖动，边缘用于改变大小。设置与打卡对话框继续使用固定窗口和内部滚动。

## 每日提肛与喝水打卡

1. 在普通浮窗下方，完成个人提肛计划后点击“提肛打卡”；达到自己的全天饮水目标后点击“喝水”。已完成会显示 ✓，再次点击可撤销。
2. 点击“历史 / 设置”，查看“今日打卡”“历史记录”“提醒与目标”。精简浮窗或隐藏浮窗时，也能从托盘菜单进入。
3. 每项每天最多计 1 次；第二天按电脑本地日期自动恢复未勾选。历史按日期保留两项状态、当日饮水目标，并显示提肛次数、喝水次数与全部完成天数。只有软件运行过的日期会有一条记录；没有记录的日期不虚构打卡。
4. 默认每天 20:00 合并提醒仍未完成的项目，每天最多一次；时间和两项提醒开关可调整。到点之后才启动软件，会补发当天提醒。全屏、锁屏、休眠以及正在处理活动提醒时延后；跨天后不追补昨天。退出软件期间不会提醒；每日打卡独立于久坐计时的暂停状态。
5. 饮水目标默认 1.5 L，可选 1.7 L 或自定义；在“提醒与目标”点击“保存提醒与目标”才生效。目标改动应用于今天及以后，并取消今天的喝水勾选，需要重新确认；历史目标不改动。只改提醒时间或开关，不取消勾选，也不会再次发送当天已发过的提醒。
6. “历史记录”以周一开头的月历显示；左右按钮切换月份，“今天”返回本月。绿色“提 / 水”表示确认完成，浅色表示未确认，无标记表示无记录。点日期查看当日目标与状态，历史日期不可在日历中修改。键盘方向键选择日期，PageUp / PageDown 换月，Home 返回今天。
7. “导入旧版记录”可选取旧文件夹中的 `sitless.checkins.xml` 或备份。补入缺失的历史日期，保留当前已有日期；仅今日完全空白且未提醒的记录可恢复旧确认。无效文件整体拒绝，不部分导入。

饮水量参考温和气候、低活动成年女性约 1.5 L、男性约 1.7 L 的**直接饮水量**，不含食物中的水；这不是适合所有人的统一合格线。个人需要随活动、气候和身体情况调整，有医嘱限液时按医嘱。不要为了打卡集中大量饮水。[国家疾控局刊载的中国疾控中心说明](https://www.ndcpa.gov.cn/jbkzzx/c100040/common/content/content_2104761364364300288.html)

提肛打卡只确认已有个人计划，不规定所有人统一的次数或时长；盆底肌训练不适合所有人，开始前可咨询专业人员，动作需充分放松，避免过量。[NIDDK 说明](https://www.niddk.nih.gov/health-information/urologic-diseases/kegel-exercises)

软件不检测实际饮水量、提肛动作或治疗效果，打卡为用户自行确认。

## 开始使用

- 默认每 **30 分钟**提醒一次，活动计时 **3 分钟**。可在 `···` 菜单中修改：提醒间隔 5–120 分钟、活动时长 1–20 分钟，也可选用 30/3 或 50/5 预设。
- 拖动浮窗背景或文字即可移动；菜单可切换为紧凑浮窗。点击 `−` 收到系统托盘，双击托盘图标恢复。
- 右上角双箭头按钮一键切换精简浮窗，精简后再点可展开；三个点打开快捷菜单，按功能分组，绿色勾选表示已开启，右侧标注快捷键。到时提醒和活动完成待确认时会暂时展开，处理后可切换。
- 点击“暂停”停止计时，再点“继续”恢复。提醒出现后，选择开始活动，或延后 5 分钟；延后不会清除已累计的桌前时间。
- 活动需由你主动开始。中途跳过不计完成次数；完整倒计时结束后暂停，等你返回点击“继续”再开始下一轮。
- 锁屏、休眠会自动暂停；恢复后保留你原先的手动暂停状态。长时间中断不会被算成完成活动。
- 只修改提示音、置顶、精简模式或活动时长时，保留已经延后的提醒；修改提醒间隔才会重新计算提醒阈值。

浮窗获得焦点时可使用以下快捷键（不是系统全局热键）：

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+, | 打开设置 |
| Ctrl+M | 切换精简浮窗 |
| Ctrl+P | 暂停 / 继续计时 |
| Ctrl+0 | 当前浮窗恢复默认大小 |
| Esc | 收起到托盘 |

精简浮窗中的“活动”开始活动倒计时，“结束”提前结束且不计完成。到时提醒和活动完成会自动展开，避免遗漏操作。

## 全屏游戏自动免打扰

- 默认开启，可在设置或托盘菜单中关闭“全屏自动免打扰”。旧版设置文件会使用开启的默认值；关闭后重新启动会保留选择。
- 检测独占 Direct3D 全屏状态，并检查前台窗口客户区是否覆盖其显示器，兼顾无边框全屏。按全屏状态判断，不只针对游戏：全屏视频和演示文稿也会进入免打扰。普通带标题栏的最大化窗口通常不会触发。
- 最迟在下一次约 1 秒的检测中隐藏浮窗，抑制提示音与气泡；计时继续，手动暂停状态保留。短暂切屏不会立刻恢复提醒，退出全屏稳定约 3 秒后恢复。
- 全屏期间到时，只保留一次待处理提醒；恢复后仍有效才补发。已手动处理或重置的旧提醒不再补发。活动完成后的“等待手动继续”规则保持不变。
- 没有新提醒时，进入前可见的浮窗会恢复；原先手动隐藏的浮窗保持隐藏。需要调整设置时仍可主动双击托盘图标打开浮窗。
- 不注入游戏、不安装键鼠钩子、不读取或保存窗口标题，不暂停游戏，也不修改 Windows 系统的免打扰设置。
- 独占全屏、不同游戏与多屏缩放的实际兼容性仍需实机验证；具体步骤见 `优化方案清单.md`。

## 提醒规则的依据

WHO 将久坐行为定义为清醒时坐着、斜倚或躺着，能量消耗不超过 1.5 MET 的行为；并非“坐满某个分钟数”才算久坐。WHO 建议减少久坐，以包括轻度活动在内的身体活动替代，但未给出适用于所有成年人的统一连续久坐时限。

默认 30 分钟提醒参考 Mayo Clinic“每 30 分钟短暂中断坐姿”的建议；**3 分钟是本软件便于执行的活动预设，不是医学界定**。50/5 预设参考英国 HSE 对屏幕工作的建议：连续工作约 50–60 分钟后，安排 5–10 分钟短休息。活动时可短距离走动、伸展或按自身能力改变姿势。

来源：[WHO 建议](https://www.ncbi.nlm.nih.gov/books/NBK566046/) · [WHO 术语](https://www.ncbi.nlm.nih.gov/sites/books/NBK566047/) · [Mayo Clinic](https://www.mayoclinic.org/healthy-lifestyle/adult-health/expert-answers/sitting/faq-20058005) · [HSE](https://www.hse.gov.uk/contact/faqs/vdubreaks.htm)

## 数据与轻量运行

使用原生 Windows 窗体，无浏览器、联网、后台服务、摄像头或键鼠钩子。不根据键鼠空闲推断起身，也不检测姿态；“今日完成”仅表示活动倒计时完成，不能证明实际站立或运动。

设置与当天统计保存在 `%LOCALAPPDATA%\SitLess\sitless.settings.xml`，每分钟、操作后和退出时保存。重新启动会开始新一轮，当天统计恢复。退出请使用浮窗或托盘菜单中的退出选项。

每日打卡保存在同一目录的 `sitless.checkins.xml`，修改后立即尝试保存，写入失败会显示提示并稍后重试；保存时维护 `.bak` 备份。主记录损坏时尝试读取备份，损坏原件在下次保存时另存为 `.damaged-*`。备份可能比最近一次操作旧，请保留整个数据文件组。

同一电脑、同一 Windows 账号下移动或升级软件，固定目录不变。首次运行时，只在固定目录没有记录时复制程序所在文件夹的旧 XML 与备份，原件不删除；旧文件在别处时从日历页导入。迁移失败时不覆盖默认数据，修复权限后重启重试。私人 XML 与备份不会纳入 Git 或便携包。

## 源码与演示

在源码目录运行 `.\build.ps1` 即可编译，无第三方库。`SitLess.exe --demo` 使用 10 秒提醒、5 秒活动，便于体验；不保存设置，可与正式计时同时运行。`--render` 用于开发预览。
