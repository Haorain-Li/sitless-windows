## 建议实施顺序

1. 先完成实际游戏兼容性验收，再做应用例外和手动免打扰，控制误判与恢复行为。
2. 接着处理设置兜底、升级识别及多屏缩放，减少使用中断和版本混淆。
3. 最后按实际需求选择工作时段、历史统计和主题，并用长期资源采样控制新增功能的开销。

## 正式版实机验收步骤

1. 从托盘退出旧版，打开待验收版本，确认设置标题与程序版本一致，勾选“全屏自动免打扰”。
2. 将提醒间隔设为 5 分钟并开启提示音，进入无边框全屏游戏，跨过提醒时点；确认没有浮窗、提示音或气泡。
3. 退出全屏等待约 3–4 秒；仍有效的到时提醒应只出现一次，不抢键盘焦点。
4. 在独占全屏模式下重复；再检查普通窗口 / 最大化窗口不会错误进入免打扰。
5. 手动暂停后进入、退出全屏；应保持暂停。手动隐藏浮窗后切换全屏，若没有新的有效提醒，不应自行展开。
6. 关闭“全屏自动免打扰”，确认全屏下恢复原提醒规则；重启确认开关状态保留。

上述步骤是待进行的实机验收说明，不代表已在实际游戏中完成。
